# COMP 570 Project 1: Montreal Neighbourhoods

Track 1 of the project: turn "which Montreal neighbourhoods are better for
living?" into a question data can answer, and build the dataset for it. The
report lives in `report/` (AAAI camera-ready LaTeX).

This README covers the data pipeline: where each source lives, how each
teammate's part is produced, and how they are joined into the final dataset
`data/final_dataset.csv` (19 boroughs x 62 columns).

## Repository layout

Data and code are sorted by owner. Each person's folder has `raw/` (inputs as
downloaded or received) and `processed/` (generated by their script).

```
data/
  final_dataset.csv                 FINAL DATASET: one row per borough (committed)
  final_dataset_report.json         its integrity checks and headline numbers
  sources_manifest.json             URL, retrieval date, licence, size of every download
  mounir/raw/                       311 requests: current file + 3 archives (not committed, ~2.5 GB)
  mounir/processed/                 Mounir's 311 outputs (not committed)
  adil/raw/                         2021 Census table (CSV + source PDF)
  adil/processed/                   cleaned census (not committed)
  shirley/raw/                      SPVM crime incidents (not committed)
  shirley/processed/                crime counts per borough (not committed)
  sebastien/raw/                    borough boundaries (GeoJSON), ISQ 2023 population
scripts/
  download_sources.py               step 0: download the City sources
  mounir/                           step 1: 311 pipeline (Mounir)
  adil/prepare_census.py            step 2: census (Adil)
  shirley/crimes.ipynb              step 3: crime (Shirley)
  build_final_dataset.py            step 4: join 311 + census + crime (Sebastien)
  make_report_figures.py            step 5: report figures and tables
report/                             LaTeX report; figures/ and tables/ are generated by step 5
```

## Running the pipeline

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 0. downloads (~2.5 GB; skips existing files, --force to refresh)
.venv/bin/python scripts/download_sources.py

# 1. 311 (Mounir), in this order
.venv/bin/python scripts/mounir/build_dataset.py      # ~5 min, reads all four 311 files
.venv/bin/python scripts/mounir/acti_nom_mapping.py   # seconds
# 2. census (Adil); must run before audit_311.py, which reads it for rates
.venv/bin/python scripts/adil/prepare_census.py
.venv/bin/python scripts/mounir/audit_311.py          # ~1 min

# 3. crime (Shirley)
.venv/bin/jupyter nbconvert --to notebook --execute --inplace scripts/shirley/crimes.ipynb

# 4. final dataset, 5. report
.venv/bin/python scripts/build_final_dataset.py
.venv/bin/python scripts/make_report_figures.py
cd report && latexmk -pdf main.tex
```

`build_final_dataset.py` stops with an error if any integrity check fails.

The City replaces its files without notice, so cite the retrieval dates in
`data/sources_manifest.json`. The boundary file has 34 polygons: the 19
boroughs (`TYPE = "Arrondissement"`) and the 15 linked cities such as
Westmount (`TYPE = "Ville liée"`), which are not part of the City of Montreal
and are excluded from every source.

## Step 1: 311 (Mounir, `scripts/mounir/`)

Mounir's code is used as he wrote it; only the folder paths in `common.py`
(and the docstrings that mention them) were changed for this layout.

- **`build_dataset.py`** reads each creation year from exactly one file:
  `requetes311.csv` for 2022 onward, then the 2019-2021, 2016-2018 and
  2014-2016 archives (the older 2017-2018 archive is superseded and not
  downloaded). It drops `Information` calls (no ID, no location), removes
  duplicate IDs and assigns each request to a borough.
- **Borough rule:** use `ARRONDISSEMENT_GEO` (where the work happens) when it
  names one of the 19 boroughs; fall back to `ARRONDISSEMENT` (the handling
  unit) only when the location field is empty; drop linked cities and rows
  with no location.
- **`acti_nom_mapping.py`** maps every category (`ACTI_NOM`, kept in French)
  by keyword rules to a group: `condition` (a resident reports a problem in
  the neighbourhood), `service` (routine city service) or `administrative`.
  Condition labels get one of five themes and a confidence (`clear` or
  `ambiguous`). No label is left unmapped.
- **`audit_311.py`** writes the funnel (`audit_2023_2025.csv`), the per-borough
  table (`borough_311_2023_2025.csv`), missingness and bias tables.
- **Outcome base:** `Requete` + `Plainte` rows in the 19 boroughs, excluding
  rows logged at a borough office (`LOC_ERREUR_GDT = 1`, whose location is the
  office, not the problem).

2023-2025 funnel (current file retrieved 2026-10-07):

| Step | Rows |
|---|---|
| Raw rows created in the window | 1,975,499 |
| minus `Information` calls | 1,061,611 |
| minus borough rule (1,540 linked city, 791 no location) | 1,059,280 |
| minus comments (`Commentaire`) | 1,041,585 requests and complaints |
| minus office-flagged (36,532) | **1,005,053 (outcome base)** |
| of which `condition` (the outcome) | 594,245 (59.1%) |

## Step 2: census (Adil, `scripts/adil/prepare_census.py`)

Adil collected the 2021 Census table from the City's *Annuaire statistique de
l'agglomération de Montréal*
(["Population totale, taux de croissance et densité - 2021"](https://ville.montreal.qc.ca/pls/portal/docs/PAGE/MTL_STATS_FR/MEDIA/DOCUMENTS/POPULATION%20TOTALE_TAUX%20DE%20CROISSANCE_DENSIT%C9_2016-2021.PDF)).
The script reads the Windows-1252 CSV and writes
`data/adil/processed/borough_population_2021.csv` (`borough`, `population`,
`population_2016`, `growth_rate_pct`, `density_per_km2`), the file Mounir's
audit expects. It stops unless the 19 boroughs sum to **1,762,949**, the
published City total (passes).

## Step 3: crime (Shirley, `scripts/shirley/crimes.ipynb`)

SPVM criminal acts, 2015 to the retrieval date (361,399 incidents), in six
categories. The notebook keeps 2023-2025, places each located incident in a
borough by point-in-polygon and writes counts per borough and category to
`data/shirley/processed/`. For 2023-2025: 97,652 incidents, **74,450 kept
(76.2%)**; 15,990 have no usable location and 7,212 fall in a linked city.
Locations are moved to the nearest intersection and dates are the reporting
date (City methodology).

## Step 4: final dataset (`scripts/build_final_dataset.py`)

Joins the three parts on the official MAMH borough code (`CODEMAMH` in the
boundary file, e.g. `REM17`). Names differ between sources (en dash vs.
hyphen, accents), so each name is normalized before lookup, and the script
stops if any borough is missing or duplicated on any side.

Columns of `data/final_dataset.csv`, in order:

- **Borough and population:** `code_mamh`, `borough`, 2021 and 2016 Census
  population, growth, density, ISQ 2023 estimate and % change.
- **311 counts (2023-2025, outcome base):** `requests_311`
  (requests + complaints), `requests_office_flagged`, `requests_condition`
  (the outcome), `requests_condition_clear_only` (sensitivity),
  `requests_service`, `requests_administrative`, five `condition_<theme>`
  columns, and the incident columns: four `cleanliness_*` parts,
  `cleanliness_total`, `rats`, `potholes` (categories in `INCIDENTS` in the
  script; all are in Mounir's `condition` group).
- **Shares:** `office_flagged_share_pct`, `administrative_share_pct`.
- **311 rates:** `rate_<count>` per 1,000 residents per year (count / 3 /
  2021 population), plus `rate_requests_condition_isq2023`.
- **Crime:** six `crimes_<category>` and `crimes_total`, their rates
  `rate_crimes_*`, plus `rate_crimes_total_isq2023`.

Integrity checks (all pass, recorded in `final_dataset_report.json`):
population sums to 1,762,949; 311 totals equal Mounir's audit (1,041,585
requests, 594,245 outcome); borough outcome rates equal Mounir's; crime total
equals Shirley's 74,450; crime categories sum to the total; no missing values.

Headline numbers (per 1,000 residents per year, city-wide): outcome 112.4,
cleanliness 24.3, potholes 5.4, rats 0.54, crimes 14.1. Spearman rank
correlation with the crime rate across boroughs: cleanliness 0.66, rats 0.54,
potholes 0.51, outcome 0.47.

### Things to watch

- **Saint-Laurent logs 18.5% of its requests at its borough office** (median
  borough 2.4%), and has the highest office-flagged + administrative share
  (29.3% vs. 16.0% city-wide). Raw 311 totals overstate it; the outcome
  columns exclude both.
- **2021 population, 2023-2025 events.** The ISQ estimate for July 2023 is
  7.5% above the 2021 Census (+5.1% Saint-Léonard to +12.3% Ville-Marie), so
  every rate is somewhat too high, most in Ville-Marie. Part of the gap is
  census undercount correction, so 7.5% is an upper bound on real growth.
  The `*_isq2023` rate columns quantify it.
- **Commuters and visitors** inflate Ville-Marie's per-resident rates.
- **Rats are a small count** (2,836 requests over three years), so borough
  rates are noisy.
